# Assignment 2 - Advanced CSS

## Description

This project was created for Assignment 2 in Web Technologies.
The main purpose of this assignment is to practice Flexbox and CSS Grid.

## Tasks

### Task 0 - Navigation Bar
A navigation bar created using Flexbox. The logo is placed on the left and navigation links are placed on the right.

### Task 1 - Card Row
Three technology cards created using Flexbox. Each card contains an image, title, description and button. The cards also have a hover effect.

### Task 2 - Grid Layout
A dashboard page created using CSS Grid. It contains a header, sidebar, main content area and footer.

### Task 3 - Image Gallery
A travel image gallery with nine images. CSS Grid is used to create three equal columns. Images have a hover effect with captions.

### Task 4 - Portfolio
A student portfolio that combines Flexbox and CSS Grid. Flexbox is used for navigation and project cards, while Grid is used for the main page layout.

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Git and GitHub

## How to Run

Open `index.html` in a web browser or use Live Server in Visual Studio Code.
